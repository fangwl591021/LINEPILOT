# LINE COPILOT v1.4 手動測試清單

## 第一屏與資訊層級

- [ ] 開啟聊天室後，不捲動即可看到客戶名稱、最近客戶訊息與「產生建議回覆」。
- [ ] Header 顯示「LINE COPILOT」與「AI 客服助手」。
- [ ] 主畫面沒有聊天室 ID、完整網址、confidence、偵測來源或測試功能。
- [ ] 客戶與聊天室資訊、開發與偵錯資訊預設收合。

## 快速操作

- [ ] 六個 pill button 全部顯示。
- [ ] 每個按鈕會填入正確指令，但不會立即呼叫 API。
- [ ] 最近選擇的快捷操作有選取樣式。
- [ ] loading 期間所有快捷按鈕停用。

## AI 輸入與結果

- [ ] 空白問題顯示可關閉的「請先輸入問題」。
- [ ] 輸入框維持約 90–110px，顯示剩餘字數。
- [ ] 「查看對話內容」顯示最多 5 則、不顯示 confidence。
- [ ] low confidence 在有可靠訊息時不帶入。
- [ ] Mock API 可顯示「測試模式」標籤。
- [ ] loading 顯示 spinner 與「正在整理建議回覆…」。
- [ ] 複製回覆正常，失敗時可手動 `Ctrl+C`。
- [ ] 重新產生使用相同需求。
- [ ] 更親切會加入指定調整文字並再次呼叫。
- [ ] 更簡短會加入指定調整文字並再次呼叫。
- [ ] 清除會重設問題、結果、錯誤與快捷選擇。
- [ ] 長結果超過 300px 時只在結果文字區捲動。

## 聊天室狀態

- [ ] 切換聊天室後摘要與預覽更新。
- [ ] 切換聊天室後舊結果清除並顯示重新產生提示。
- [ ] 切換聊天室後尚未送出的問題與 checkbox 偏好保留。
- [ ] 未開啟聊天室時顯示「尚未選擇聊天室」。
- [ ] 未開啟聊天室時 context checkbox 停用，但手動問題仍可使用。
- [ ] 無聊天室 payload 的 contactName／conversationId 為 null，visibleMessages 為空。

## 折疊與技術資訊

- [ ] 客戶資訊展開後才看見 ID、網址、來源與 confidence。
- [ ] 偵錯區包含候選、排除原因、payload、response metadata、requestId、model、usage 與 Mock 狀態。
- [ ] 匯出偵測報告正常。
- [ ] 複製 Header 診斷 JSON 正常。
- [ ] footer 的「開發與偵錯」會打開並捲到偵錯區。
- [ ] 收合再展開後，輸入、結果、checkbox、錯誤與折疊狀態保留。

## LINE OA 安全與回歸

- [ ] 面板只建立一個實例。
- [ ] LINE OA 原生輸入框內容不變。
- [ ] LINE OA 原生傳送按鈕沒有被點擊。
- [ ] 沒有呼叫 LINE Messaging、Push 或 Reply API。
- [ ] footer 不遮住 AI 結果與主要內容。
- [ ] SPA 切換與 DOM 重繪後面板仍存在。
