# LINEPILOT v2.0 免費版測試清單

## 安裝與註冊

- [ ] Manifest 顯示 2.0.0，名稱為「LINEPILOT 免費版」。
- [ ] 未登入時可在 popup 完成註冊。
- [ ] 註冊成功後顯示 FREE 免費方案。
- [ ] 重新開啟 Chrome 後仍可登入；登出後清除 LINEPILOT Token。

## 免費知識庫

- [ ] SaaS 後台可新增、列出及刪除知識。
- [ ] 免費方案最多 100 筆。
- [ ] Extension 只在登入後讀取自己的知識庫。
- [ ] 未登入時產生建議會提示先完成免費註冊。
- [ ] 問題命中知識時顯示標準回答與知識來源。

## 聊天室與三段式介面

- [ ] 可收合為懸浮圖示。
- [ ] 可展開為右側工作面板。
- [ ] 可切換為全螢幕三欄工作台。
- [ ] 只讀取目前可見的最近 5 則文字對話。
- [ ] 切換聊天對象後清除上一位客戶的建議。

## 安全

- [ ] 不讀取 LINE Cookie、Token 或既有 Authorization Header。
- [ ] 不修改 LINE 原生輸入框。
- [ ] 不點擊 LINE 傳送按鈕。
- [ ] 不呼叫 LINE Push／Reply API。
- [ ] 不保存聊天內容。
