# LINE COPILOT v1.3 測試檢查清單

## 安裝與顯示

- [ ] Extension 可在 `chrome://extensions` 正常載入，版本為 1.3.1。
- [ ] LINE OA 頁面右側只顯示一個 LINE COPILOT 面板。
- [ ] 收合再展開面板後，問題與 AI 結果仍保留。

## 輸入與 MLM 知識庫

- [ ] 輸入「負離子眼鏡有什麼功能」，結果命中防藍光與 UV400 的 MLM 知識。
- [ ] 結果的建議來源顯示「MLM 知識庫（本機比對）」。
- [ ] DevTools Network 中沒有上傳問題或聊天內容到 GitHub 或 MLM。

## 輸入與 Mock API fallback

- [ ] 空白問題顯示「請先輸入問題」，不呼叫 API。
- [ ] 1 個字元顯示至少 2 個字元的提示。
- [ ] 超過 2,000 字不可輸入，剩餘字數正確更新。
- [ ] Enter 不送出，Shift + Enter 可輸入換行。
- [ ] Mock API 顯示約 800ms loading，期間按鈕 disabled。
- [ ] Mock 建議、產生時間、聊天對象及上下文狀態正確顯示。
- [ ] 快速多次點擊只建立一個請求。
- [ ] 重新產生使用相同問題再次呼叫 API。
- [ ] 清除會移除問題、結果與提示。

## 上下文

- [ ] 預設勾選「帶入目前聊天室最近訊息」。
- [ ] 最多預覽／傳送 5 則非空白文字訊息。
- [ ] 有 high／medium 訊息時不帶入 low confidence。
- [ ] 只有 low confidence 時可帶入 low confidence。
- [ ] 取消 checkbox 後顯示 0 則且 payload 的 `visibleMessages` 為空。
- [ ] 切換聊天室後，聊天對象、conversationId、URL 與預覽內容更新。
- [ ] 未開啟聊天室時仍可用手動問題產生建議。

## 複製與錯誤

- [ ] 一鍵複製成功後顯示「已複製，可貼到 LINE OA 聊天輸入框」。
- [ ] Clipboard API 失敗時選取建議文字並提示按 `Ctrl+C`。
- [ ] API Base URL 未設定且 Mock 關閉時顯示設定錯誤。
- [ ] Timeout、網路錯誤、401、403、429、500+ 顯示指定繁體中文訊息。
- [ ] suggestion 空白時顯示無可用建議。

## LINE OA 安全回歸

- [ ] Extension 不讀取 Cookie、localStorage、Authorization Header 或 LINE Token。
- [ ] Extension 不攔截 LINE OA 網路請求。
- [ ] Extension 不修改 LINE OA 原生聊天輸入框。
- [ ] Extension 不點擊 LINE OA 傳送按鈕。
- [ ] Extension 不呼叫 LINE Messaging API、Push API 或 Reply API。
- [ ] 沒有點擊「產生 AI 建議」時，不會上傳聊天室內容。
- [ ] Mock 模式完全不發送外部 API request。
