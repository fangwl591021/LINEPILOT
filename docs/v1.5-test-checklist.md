# LINE COPILOT v1.5 測試清單

## 客戶識別

- [ ] 開啟 `chat.line.biz` 聊天室後顯示正確姓名、頭貼與 `U...` 聊天室 ID。
- [ ] 點擊「複製」後剪貼簿只有目前聊天室 ID。
- [ ] 同名但頭貼不同的 Profile 只在名稱＋頭貼唯一匹配時顯示 K 點。
- [ ] 尚未對應時顯示「尚未取得」，不可顯示 0 K點。
- [ ] 切換聊天室後，姓名、頭貼、UID 與 K 點資料一起更新。
- [ ] 未開啟聊天室時不顯示舊客戶的 UID 或 K 點。

## MLM 登入

- [ ] 錯誤帳密顯示登入失敗，不殘留密碼。
- [ ] 正確客服帳號取得短效登入並自動讀取目前客戶。
- [ ] 重新整理 LINE OA 後要求重新登入，證明 Token 未持久化。
- [ ] 登出後立即清除 K 點資料與可操作按鈕。

## K 點

- [ ] 康立智能與康立全球餘額分開顯示。
- [ ] 未對應母站會員時禁止贈點與扣點。
- [ ] 康立全球的「贈 K 點」保持停用。
- [ ] 未輸入整數數量或操作原因時不呼叫 API。
- [ ] 取消確認視窗時不呼叫 API。
- [ ] 贈點／扣點成功後顯示新餘額並重新讀取。
- [ ] 切換聊天室期間，不把上一位客戶的回應套到新客戶。

## 安全與回歸

- [ ] Extension 原始碼與 Console 不包含管理 Token、密碼或 LINE Token。
- [ ] background 僅允許登入、客戶摘要、K 點流水、贈點與扣點白名單端點。
- [ ] 不修改 LINE OA 輸入框、不點擊傳送、不自動發訊息。
- [ ] 側欄、全螢幕、Esc 返回、AI 建議與聊天室偵測仍正常。
